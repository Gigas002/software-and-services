# yazi

config is the same as linux, location differs

Also, set environment variable `YAZI_FILE_ONE` in order to see files preview. The `file.exe` used is in `git` installation

## Plugins

Same as linux, except linux-only `chmod` and `mount` plugins (and their keybinds in `keymap.toml`)

Install everything from `package.toml` with: `ya pkg install`
